Về Chúng Tôi

Đây là bài Lab 5 thuộc môn Thiết kế Web đáp ứng (Responsive Web Design).

Website được xây dựng nhằm tối ưu hóa trải nghiệm người dùng trên mọi thiết bị (Desktop, Tablet, Mobile) với kiến trúc mã nguồn sạch, tích hợp Flexbox, Grid và JavaScript DOM tương tác.
